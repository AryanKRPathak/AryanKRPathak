## 🏆 Flagship Project

### [HRMS — AI HR Copilot](https://github.com/AryanKRPathak/HRMS)

> AI-powered enterprise HR workflow assistant built on RAG.

**Problem:** Employees waste hours searching for policy, leave, payroll and compliance information across scattered documents and HR portals.

**Solution:** Built an AI Copilot that retrieves company policies, answers HR queries in natural language, and guides employees through complex workflows end-to-end.

**Key Features:**
- 📚 Policy Retrieval (RAG)
- ⚖️ HR Compliance Copilot
- 💰 Payroll Assistant
- 🗓️ Leave & Attendance Assistant
- 🚀 Onboarding Copilot
- 🔄 Employee Self-Service Workflows

**PM Artifacts:**
- 📄 PRD | 🗺️ User Journey Maps | 📊 KPI Framework
- 🧪 AI Evaluation Plan | ⚠️ Risk Analysis | 🏗️ Architecture Diagram

**Stack:** TypeScript · RAG · Vector DB · OpenAI API
