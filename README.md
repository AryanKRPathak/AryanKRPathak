# Flagship Project

## [AI HR Copilot](https://github.com/AryanKRPathak/HRMS)

An AI-powered HR workflow assistant designed to improve employee self-service and reduce HR support load.

### Problem

Employees struggle to find:

- HR policies
- Leave information
- Payroll guidance
- Reimbursement processes
- Compliance information

HR teams repeatedly answer the same questions.

### Solution

Built an AI-powered HR Copilot that:

- Retrieves HR policies using RAG
- Answers employee questions
- Assists onboarding workflows
- Provides payroll guidance
- Supports leave and attendance queries
- Acts as an HR Compliance Assistant

### AI Components

- OpenAI API
- RAG Pipeline
- Vector Search
- Prompt Engineering
- Workflow Automation

### PM Deliverables

- KPI Framework

- MVP Roadmap

### Success Metrics
